# Selah · 注释译本（简体中文）

希伯来圣经古典注释的简体中文译本，由 Selah 项目制作——每位注释家一个
目录，每条注释一个 EDN 文件（`<注释家>/<书卷>/<章>/<节>.edn`），译自
Selah 的英文译本（英文译本则译自公有领域的希伯来原文）。

译本恪守本项目的规范：神圣名号一律音译（雅威、以罗欣、阿多奈……），
注释中的希伯来引文保持希伯来原文——逐字母机械校验——字母数值
（gematria）的算术保持注释家原样。

注释家：巴阿勒·哈图林 · 希兹库尼 · 达阿特·泽克尼姆 · 伊本·以斯拉 ·
克利·雅卡尔 · 光明生命（Or HaChaim）· 拉贝努·巴希亚 · 拉姆班 ·
拉什巴姆 · 斯福尔诺。

[Selah 项目](https://selahproject.org)的一部分。
